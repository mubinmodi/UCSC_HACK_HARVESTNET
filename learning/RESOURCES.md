# HarvestNet MVP Resources

## Knowledge

- [Project: `docs/MVP_DESIGN.md`](../docs/MVP_DESIGN.md)
  The current design: agents, fair share, workflows, screens, records, demo, build order. Use for: everything. It wins over lessons.
- [Project: `docs/adr/` decisions 0001–0009](../docs/adr/)
  Why each rule exists. Use for: defending a choice, especially ADR 0001 (no supervisor), 0002 (no invented numbers), 0009 (fair share).
- [Project: `CONTEXT.md`](../CONTEXT.md)
  The canonical vocabulary. Use for: exact wording in pitches and lessons.
- [Primary: the Cisco challenge statement](../docs/CHALLENGE.md)
  The judges' own Level 1–3 criteria and scoring areas. Use for: what "counts" for Level 3.
- [Primary: coffeeAGNTCY Lungo README](https://github.com/agntcy/coffeeAgntcy/blob/main/coffeeAGNTCY/coffee_agents/lungo/README.md)
  The organizers' reference app, built around supervisor agents. Use for: the contrast "Lungo has a supervisor, ours doesn't."
- [Primary: AGNTCY app-sdk README](https://github.com/agntcy/app-sdk)
  What the SDK actually provides (A2A, SLIM, Directory, Observe) and what's marked experimental. Use for: architecture questions and build planning.
- [Primary: A2A protocol specification](https://a2a-protocol.org/latest/specification/)
  The agent-to-agent message protocol HarvestNet's negotiators speak. Use for: message, agent card, and discovery details.
- [Primary: USDA FNS TEFAP memo FD-036, recordkeeping and eligibility](https://fns-prod.azureedge.us/sites/default/files/fdd/FD-036-record-keeping.pdf)
  States may treat SNAP participants as automatically income-eligible for TEFAP, and self-declaration is allowed. Use for: defending "SNAP as an eligibility signal."
- [Primary: Ecology Center, Market Match](https://ecologycenter.org/marketmatch/)
  California's CalFresh match at farmers markets and other farm-direct sites. Use for: the SNAP produce-program link, and which markets participate.
- [Primary: UC Davis Postharvest produce fact sheets](https://postharvest.ucdavis.edu/produce-facts-sheets/strawberry)
  Storage and temperature facts per crop. Use for: sourcing real produce-profile values.

## Wisdom (Communities)

- Cisco's coffeeAGNTCY workshop at the hackathon (time and room posted on the event Discord, per the challenge statement)
  Use for: testing the "no supervisor" architecture against the people who built AGNTCY.
- [AGNTCY GitHub discussions and issues](https://github.com/agntcy)
  Use for: SDK questions, especially SLIM group chat and Directory setup.
- A local food bank or pantry operations lead (a draft questionnaire, written for the earlier design, is in `future scope/whole-chain design/COORDINATOR_QUESTIONNAIRE.md`)
  Use for: checking whether fair share, pickup windows, and transport terms match real operations.
